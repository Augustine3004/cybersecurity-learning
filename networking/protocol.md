# Network Protocols

## What is a Network Protocol?
A network protocol is an established set of rules that dictates how different devices transmit, receive, and interpret data across a computer network

## Why Do We Need Protocols?
They are required for computer to properly communicate across the network in both wired and wireless environment.

- Message Pattern

## Common Network Protocols
## TCP
TCP stands for Transmission Control Protocol., a core standard that defines how computing devices and application programs send reliable, ordered messages across a network.
## UDP
User Datagram Protocol (UDP) is a fast, connectionless network protocol used to send data packets quickly across a network without establishing a prior connection

## HTTP
HTTP (Hypertext Transfer Protocol) is the foundational set of rules used by web browsers and servers to communicate and transfer data on the World Wide Web.

## HTTPS
HTTPS stands for Hypertext Transfer Protocol Secure, which is a safe way to send data between your web browser and a website.

## DNS
Domain Name System (DNS) is a system that translates human readable domain names into IP addresses that computer use to communicate.

## DHCP
This is a network management protocol that automatically assigns IP addresses and configuration settings to devices as they connect to a network.

## SSH
SSH (Secure Shell) is a network protocol that lets you safely log into, control, and transfer files between computers over an unsecured network.

## FTP
File Transfer Protocol is a standard communication protocol used for the transfer of files form a server to a client over a network.

## ICMP
ICMP (Internet Control Message Protocol) is a network-layer protocol used by devices to report errors and share operational status updates.
