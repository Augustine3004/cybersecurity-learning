# Computer Fundamentals

## What is a Computer?

A computer is an electronic device that receives data as input, processes the data according to instructions, stores data, and produces information as output.

### The Basic Computer Process

1. Input
2. Processing
3. Storage
4. Output

---

## Main Components of a Computer

### CPU (Central Processing Unit)

The CPU is the brain of the computer, it is responsible for executing instructions and performing calculations.


### RAM (Random Access Memory)

RAM is temporary, high-speed memory used to store data and instructions that the CPU needs quick access to.

RAM is volatile, meaning its contents are normally lost when the computer is powered off.

### Storage

Storage devices keep data and information permanently or for long-term use.

Examples include:

- HDD (Hard Disk Drive) - uses older technology with moving parts, limiting it's performance
- SSD (Solid State Drive) - Have no moving parts and use memory chips, allowing much faster speed

Unlike RAM, storage is non-volatile.

### Motherboard

The motherboard is the main circuit board that connects major components of a computer and allows them to communicate. Every other components connects through the motherboard 

### Network Interface Card (NIC)

A NIC allows a computer to connect to a network. There are wired and wireless NIC , often imbedded in the motherboard but can also be added as expansion card. They typically connect via PCI, express ports

It can provide:

- Ethernet connectivity
- Wi-Fi connectivity

---

## Hardware vs Software

### Hardware

Hardware refers to the physical components of a computer that can be physically touched.

Examples:

- CPU
- RAM
- Motherboard
- Keyboard
- SSD
- Network card

### Software

Software consists of programs and instructions that tell the computer what to do.

Examples:

- Windows
- Linux
- Web browsers
- Text editors
- Security software

---

## Operating System

An operating system (OS) is system software that manages computer hardware and provides services for applications.

Examples include:

- Windows
- Linux
- macOS
- Android

The operating system manages resources such as:

- CPU
- Memory
- Storage
- Files
- Network connections
- Processes
- Devices

---

## Processes

A process is a program that is currently being executed by the operating system.

For example, when you open a web browser, the operating system creates one or more processes to run it.

Processes use system resources such as:

- CPU time
- RAM
- Network resources
- Storage

---

## Files and File Systems

A file is a collection of data stored under a name.

A file system is the method an operating system uses to organize and manage files on storage devices.

Examples include:

- NTFS
- FAT32
- exFAT
- ext4

Files are organized into directories or folders.

---

## Computer Security Fundamentals

Some basic security principles include:

- Use strong, unique passwords.
- Keep operating systems and software updated.
- Use appropriate access controls.
- Avoid opening suspicious files or links.
- Back up important data.
- Use security software where appropriate.
- Protect sensitive information.

## What I Learned

- A computer receives input, processes data, stores information, and produces output.
- The CPU executes instructions.
- RAM provides temporary working memory.
- Storage provides long-term data storage.
- Hardware is the physical part of a computer.
- Software consists of programs and instructions.
- An operating system manages hardware and software resources.
- Processes are running instances of programs.
